## Field Note

WSCAD ELECTRIX is easier to trust when the job stays smaller than the full machine it came from. A named session shows which cabinet is active, the pins show which devices you will place today, and the closing note tells the next person how the schematic pages feed the terminal plan. That record is short on purpose: not a copy of every part, only the path back to the layout that is still open.

The same loop fits a student enclosure, a client machine, or a computer shared by two detailers. Open the last WSCAD ELECTRIX session, match one device from the part database, and leave the shop drawing easier to follow than you found it. Loose markups stay where they are. WSCAD ELECTRIX only holds the cabinet layout, the summary, and the handoff.

## One Real Pass

Pick a machine that already has a name: a conveyor panel, a pump starter, or a small control cabinet. Open it in WSCAD ELECTRIX, keep only those devices on the board, and trace one terminal you can point to. A pass is done when that terminal matches the schematic page and the extra parts are no longer in the way. WSCAD ELECTRIX does not need a full machine redraw before it is useful.

If the pass feels crowded, the job is too wide. Drop anything that belongs to a different cabinet and leave it out of this workspace. The next pass can have its own title. What matters is that this one stays readable from the first schematic page to the cabinet layout, with the summary still matching the terminal plan on the board.
